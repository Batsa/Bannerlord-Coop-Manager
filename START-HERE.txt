Bannerlord Coop Manager - Quick Start
=====================================

1. Extract this ZIP completely to a normal writable folder.
2. Keep all extracted files together.
3. Run "BCS Tool.exe".

No installer, .NET runtime, SDK, or source build is required.

BCSTool.RuntimeBootstrap.dll must remain beside BCS Tool.exe. It is required
when the manager starts a modded dedicated-server profile.

This ZIP does not include Mount & Blade II: Bannerlord, Bannerlord Coop,
Empires of Europe 1700 (EOE), or the dedicated-server package. Install those
separately before configuring the manager.

Supported overhaul setup in Server Mods is only:
1. Drag the overhaul module folder onto the list.
2. Click "Prepare / Install Bridge".

That operation enables and orders the required modules, installs/repairs all
bridge-owned server files, and creates the matching client ZIP. Analyze,
checkboxes, manual ordering, and Save Load Order are not required.

Optional population limits are available afterward by selecting the enabled
generated bridge row and clicking "Bridge Population Settings". They are not
required for initial setup and apply after the next server start. Automatic NPC
caravans default to two per town; the editor shows the calculated overhaul-wide
target and lets the server owner select zero through ten per town.

This preview executable is not digitally signed. Windows may display an
"Unknown publisher" or SmartScreen warning. Before running it, compare the
ZIP's SHA-256 hash with the .sha256 file published beside the ZIP on GitHub.

Full setup, supported versions, EOE bridge installation, client package installation,
save import steps, current progress, and known limitations are in README.md.
